# ふれあいの里（有料老人ホーム）— 7月オープン向け

## 結論：**できます**

看護師が常駐しない有料老人ホームでも、本アプリの **介護記録の中核** はそのまま使えます。  
看護師向けの画面だけ出さない／弱める運用で対応可能です。

---

## ふれあいの里でそのまま使える機能

| 機能 | 備考 |
|------|------|
| 入居者名簿・異常監視 | 食事・排便・巡視の色分け |
| 生活記録（食事・水分・排便・巡視） | 現場の主業務 |
| 申し送り（施設共通・個室メモ） | |
| ヒヤリハット・事故報告 | 台帳連携 |
| 名簿管理（アプリ内 CRUD） | スプレッドシート種取り込み後 |
| クラウド同期（複数PC） | テナント別 organization |
| バイタル記録・異常アラーム | 看護師がいなくても介護職が入力可能 |
| 入退院・入居記録、情報提供書（救急時） | 看護師欄は空欄 or 施設長で代替 |

---

## 看護師常駐施設向け（ふれあいの里では基本オフ）

| 機能 | ふれあいの里での扱い |
|------|----------------------|
| 看護事務モード（訪看・特別指示の手動登録） | スタッフプロフィールで **ON にしない** |
| 往診カレンダー PDF 取込・FAX用往診ノート | 使わない（非表示化も可） |
| 看護指示の掲示パネル | 使わない or 医療連携時のみ |
| 訪問看護特別・算定人数の警告 | 表示しない |
| 勤務表の「看護師」部署・夜勤自動割当 | 施設定義で看護部署を入れない |

**現状:** 看護事務 UI は `設定 → スタッフプロフィール → 看護事務モード` が ON の端末だけ表示されます。  
ふれあいの里の端末では **最初から OFF** にすれば、往診・訪看まわりは出ません。
